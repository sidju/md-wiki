# Tooling Philosophy

#design #tools

When selecting tools for zettelkasten management, the application-agnostic principle guides choices.

## Essential Features

A minimal zettelkasten tool must provide:

1. **Backlinks** - Seeing what links to a page is essential for discovery
2. **Search** - Finding notes by content, not just filename
3. **Standard markdown** - No proprietary extensions required

## My Choices

- **md-wiki** - This tool. Static site generator with backlinks and category pages
- **zk** - Flexible CLI for search and organization
- **Any markdown editor** - VS Code, Vim, whatever works

## The Trade-off

Obsidian offers a richer workflow but encourages non-standard features. Once you rely on wikilinks, dataview queries, or canvas files, your notes require Obsidian-compatible tools.

The agnostic path accepts slightly less ergonomic editing in exchange for universal compatibility.
